SCREENSHOTS (App Store Connect > the version > Mac screenshots)

RULES (App Store Connect Help, "Screenshot specifications", read 2026-10-11)
- Mac: required. One of these sizes, all 16:10: 1280 x 800, 1440 x 900, 2560 x 1600, 2880 x 1800.
- At least 1 and at most 10 screenshots. JPEG or PNG, no alpha channel / transparency.
- "If your app's user interface is consistent across multiple ... localizations, you only need to provide screenshots for the highest required resolution" (they are scaled down). So one set in 2880 x 1800 covers every locale in appstore/localizations.
- Guideline 2.3.3: screenshots must show the app in use, not only title art or a login page. Text and image overlays are allowed.
- Guideline 2.3.8: fit for a 4+ rating. 2.3.9: you must hold the rights to everything shown; show fictional account data, never a real login.

FAST PATH (acceptable for a first submission, 1440 x 900, works on macOS with no extra tools)
  mkdir -p /tmp/mas && for n in 03-movies 02-search 05-player 06-pip 01-live; do \
    sips -c 1125 1800 docs/screenshots/$n.jpg --out /tmp/mas/$n-c.jpg >/dev/null && \
    sips -z 900 1440 /tmp/mas/$n-c.jpg --out /tmp/mas/$n-1440x900.jpg -s format jpeg >/dev/null; done
  (crops 5 px, then scales down by 0.8; checked: five 1440 x 900 JPEGs, no alpha.) Never scale up to 2560 x 1600 or 2880 x 1800: that only blurs.

NEVER USE
- Real posters, channel logos, TV or film stills (other than Blender Foundation open movies), even blurred.
- A provider name, a server address, a username or an M3U link that carries a login, anywhere on screen (Settings, the Test connection field, the Downloads list file paths).
- The names or icons of other platforms or stores (2.3.10).
